### 📐 Systems Architecture Flow

```text
[ Client Request ]
       │
       ▼
┌──────────────────┐      Async Event
│ Reverse Proxy    │ ────────────────────► [ Message Broker / Queue ]
│ (Nginx / Gateway)│                                 │
└────────┬─────────┘                                 ▼
         │ REST / gRPC                       [ Background Workers ]
         ▼                                           │
┌──────────────────┐       O(1) Read                 ▼
│ Core Services    │ ◄───────────────────► [ Redis LRU Cache ]
│ (Go / Python)    │                                 │
└────────┬─────────┘                                 │ Cache Miss
         │ Write-Through / ACID Transaction          │
         ▼                                           ▼
┌────────────────────────────────────────────────────────┐
│ PostgreSQL / Relational Database (Primary Cluster)    │
└────────────────────────────────────────────────────────┘
```
